# CausePro WordPress Theme

CausePro is a heartfelt, trustworthy, and action-oriented WordPress theme designed specifically for non-profit and charitable organizations. It's built to be clean, professional, and optimized to help you maximize online donations and grow supporter engagement.

## Installation

1.  Download the theme as a `.zip` file.
2.  From your WordPress dashboard, navigate to **Appearance > Themes**.
3.  Click the **Add New** button at the top of the page.
4.  Click the **Upload Theme** button.
5.  Choose the `causepro.zip` file you downloaded and click **Install Now**.
6.  Once the theme is installed, click **Activate**.

## Theme Features

*   **Custom Post Types**: Easy-to-manage sections for your organization's "Causes" and "Events".
*   **Homepage Built with the Customizer**: A fully widgetized homepage template that gives you control over content and layout directly from the live Customizer.
*   **Donation-Focused Design**: A highly prominent "Donate Now" button is always visible in the header.
*   **Responsive & Accessible**: Designed to work beautifully on all devices, from mobile phones to desktops, and built with accessibility best practices in mind.

## Setting up the Homepage

To get the custom homepage layout, you need to set it as your site's front page.

1.  From your WordPress dashboard, go to **Pages > Add New**.
2.  Give the page a title, like "Home".
3.  In the "Page Attributes" box on the right, find the **Template** dropdown and select **Homepage**.
4.  Click **Publish**.
5.  Now, go to **Settings > Reading**.
6.  Under "Your homepage displays", select **A static page**.
7.  For the "Homepage" dropdown, select the "Home" page you just created.
8.  Click **Save Changes**.

## Using the Customizer

Most of the theme's options are controlled via the WordPress Customizer (**Appearance > Customize**).

### Theme Options Panel

Here you can set global options for your site.

*   **Global Donation Link**: Set the URL for the main "Donate Now" buttons here. This link will be used by the header button and other prominent CTAs.
*   **Colors**: Change the main accent color for your site. This affects links, buttons, and other highlights.
*   **Footer**: Customize the copyright text that appears in the footer of your site.

### Homepage Sections Panel

This panel gives you full control over the content and layout of your homepage.

*   **Section Display Order**: Assign a number to each section to control its position on the page. Lower numbers appear first (e.g., 10 will appear before 20).
*   **Hero Section**: Set the main headline and background image for the top of your homepage.
*   **Our Impact Section**: Showcase your organization's achievements with up to four key statistics. You can set an icon (using a [Dashicon](https://developer.wordpress.org/resource/dashicons/) class name), a number, and a short description for each.
*   **Current Causes Section**: Set the headline for this section. It will automatically display the 3 most recent "Causes".
*   **Campaign Feature Section**: Highlight a major campaign. You can set a headline, text, and a progress bar by entering a "Goal Amount" and an "Amount Raised".
*   **Upcoming Events Section**: Set the headline for this section. It will automatically display the next 3 upcoming "Events".

## Managing Content

### Causes

To add a new cause, go to **Causes > Add New**. Fill in the title, a description of the cause, and set a Featured Image. These will be displayed on the homepage and on the "Causes" page.

### Events

To add a new event, go to **Events > Add New**. Along with the title and description, you can add the following details in the "Event Details" box:

*   **Event Date & Time**: The date and time of the event.
*   **Location**: The physical or virtual location of the event.
*   **Registration/Info Link**: A URL for users to register or learn more.

You can also categorize events by "Event Type" (e.g., Fundraiser, Webinar) using the box on the right.
